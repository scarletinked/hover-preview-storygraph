# Hover Preview for StoryGraph

A small Chrome extension for [The StoryGraph](https://app.thestorygraph.com). Hover over a book cover for about half a second and a popup shows that book's genres, description, and community rating, without clicking through to its page.

**Unofficial and not affiliated with, endorsed by, or sponsored by The StoryGraph.**

## Install

Chrome doesn't have this in the Web Store, so you install it as an unpacked extension:

1. Download or clone this repository.
2. Open `chrome://extensions` in Chrome.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and select this folder.
5. Visit [app.thestorygraph.com](https://app.thestorygraph.com) and hover over any book cover.

To pick up changes after editing the code, click the refresh icon on the extension's card in `chrome://extensions` and reload any open StoryGraph tabs.

## How it works

- A content script runs only on `app.thestorygraph.com` and listens for hover on `<a href="/books/...">` links that wrap a cover image.
- After ~500ms of continuous hover, it fetches that book's page (`/books/<id>`) and its community-reviews fragment (`/books/<id>/community_reviews`) in the background, and parses out the genres, description, and star rating.
- Results are cached per book for the rest of the page session, so re-hovering the same cover is instant.
- The description shown is StoryGraph's own truncated preview (the same text visible before clicking "Show More" on their page) — not the full text.

StoryGraph doesn't offer a public API, so this works by reading the same HTML the page itself renders. If StoryGraph changes their markup, the popup may stop finding data until the selectors in `content.js` are updated.

## Files

- `manifest.json` — extension manifest (Manifest V3)
- `content.js` — hover detection, fetching, parsing, and popup rendering
- `content.css` — popup styling
- `icons/` — toolbar/store icons (generated by `generate_icons.py`)

## Publishing to the Chrome Web Store

This repo is ready to be loaded unpacked as-is. If you want it listed in the Web Store instead:

1. Register a [Chrome Web Store developer account](https://chrome.google.com/webstore/devconsole) (one-time fee).
2. Zip this folder's contents.
3. Upload it in the developer dashboard, fill in the store listing (screenshots, description, category) and the privacy-practices disclosure (justifying the `app.thestorygraph.com` host permission).
4. Submit for review.
